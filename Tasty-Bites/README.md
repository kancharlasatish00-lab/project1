# Tasty Bites Restaurant Website

A beginner-friendly static restaurant website made with HTML, CSS, and JavaScript.

## Project files

- `index.html` — Home page, specials, menu, about, gallery, and contact form.
- `login.html` — Login form demonstration.
- `register.html` — Registration form demonstration.
- `style.css` — Shared styling and responsive layouts.
- `script.js` — Mobile navigation and basic client-side form validation.
- `images/README.txt` — Notes about adding optional image assets.

## How to run

1. Download and extract `Tasty-Bites-Website.zip`.
2. Open the extracted `Tasty-Bites` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Use the navigation links to open the menu sections, login page, and registration page.

## Important limitation

This is a static front-end learning project. The forms only demonstrate browser-side validation. They do not send messages, create accounts, authenticate users, or store information. Do not enter real passwords. A production system needs a secure backend, server-side validation, password hashing, and a database.

## Customization

- Change the restaurant name, prices, address, phone, and email in `index.html`.
- Change colors and layout in `style.css`.
- Update front-end behavior in `script.js`.
- Optional food photos can be added in the `images` folder and referenced from CSS or HTML.
